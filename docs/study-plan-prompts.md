# 토플 5.0 준비: AI 프롬프트 세트 + 11·12월 플랜

2026-10-27 기준

## 목표와 전제

목표는 1월 말 응시에서 네 영역 평균 5.0(CEFR C1)이다. 오버롤은 네 영역 평균을 반 밴드 단위로 반올림하므로, 약한 영역 하나는 4.5여도 강한 영역 5.5로 메울 수 있다.

- 공부 시간: 하루 3시간, 주 6일 (일요일은 복습만 하거나 쉰다)
- 도구: 무료 온라인 모의고사(ETS Sample Test, Magoosh 무료 모의, toeflmocktests.com) + ChatGPT + Claude
- 역할 분담: 문제 풀이와 듣기 음원은 모의고사 사이트, 오답 분석·첨삭·면접 연습·어휘 퀴즈는 AI
- 1월 초에 유료 공식 모의(ETS TestReady) 1회로 실제 밴드를 확인한다

## 공통 프롬프트

새 대화를 열 때마다 세팅 프롬프트를 먼저 붙여넣으면 AI가 개편 시험 기준으로 답한다. 영역별 프롬프트는 이 세팅 뒤에 이어서 쓴다.

### 세팅 프롬프트 (대화 시작 시 1회)

```
너는 2026년 1월 개편된 TOEFL iBT 전문 코치야. 나는 overall 5.0(1~6 밴드)을 목표로 1월 말 시험을 준비 중이야.
개편 시험 구조를 기준으로 답해줘:
- Reading: Complete the Words, Read in Daily Life, Read an Academic Passage (2모듈 적응형)
- Listening: Listen and Choose a Response, Conversation, Announcement, Academic Talk (2모듈 적응형)
- Writing: Build a Sentence, Write an Email, Write for an Academic Discussion
- Speaking: Listen and Repeat, Take an Interview
채점할 때는 1~6 밴드(0.5 단위)로 점수를 주고, 후하게 주지 말고 실제 채점 기준처럼 엄격하게 해줘.
설명은 한국어로, 예문과 모범답안은 영어로 해줘.
```

### 오답 기반 어휘 퀴즈 (매일)

```
아래는 오늘 틀리거나 몰랐던 단어/표현이야.
[단어 목록 붙여넣기]
1) 각 단어의 토플식 영영 뜻, 한국어 뜻, 학술 예문 1개를 표로 정리해줘.
2) 그다음 이 단어들로 퀴즈 10문제를 내줘 (빈칸 채우기 5, 동의어 고르기 5). 정답은 내가 다 답한 뒤에 알려줘.
```

### 주간 누적 복습 (일요일)

```
이번 주 오답 노트야.
[노트 붙여넣기]
내가 반복해서 틀리는 패턴을 영역별로 3개씩 뽑고, 다음 주에 집중할 연습을 하루 단위로 제안해줘.
```

## 리딩 프롬프트

리딩은 모의고사로 풀고 AI로 오답 원인을 잡는 게 기본이다. 적응형이라 1모듈 실수가 치명적이니, 오답 유형을 줄이는 데 집중한다.

### 오답 분석

```
아래는 TOEFL 리딩 지문, 문제, 내 답, 정답이야.
[지문 / 문제 / 내 답 / 정답 붙여넣기]
1) 정답의 근거 문장을 지문에서 찾아 표시해줘.
2) 내가 고른 선지가 왜 틀렸는지 (범위 초과, 반대 진술, 지문에 없음 등) 오답 유형으로 분류해줘.
3) 다음에 같은 유형을 피하는 요령을 한 줄로 정리해줘.
```

### Complete the Words 연습 생성

```
대학 교양 수준(생물/역사/심리 중 랜덤) 학술 문단을 70~90단어로 만들어줘.
둘째 문장부터 단어 10개를 골라 뒷부분 절반 정도의 철자를 지워서 보여줘 (예: environ____).
내가 답하면 채점하고, 틀린 단어는 철자와 품사·문법 이유를 설명해줘.
```

### Read in Daily Life 연습 생성

```
대학 캠퍼스 공지문, 이메일, 안내문 중 하나를 120~180단어로 만들어줘.
세부 정보, 목적, 추론 문제를 섞어서 4지선다 3문제를 내고, 내가 답한 뒤 채점과 근거를 알려줘.
```

### 학술 지문 구조 분석

```
아래 지문을 문단별로 한 줄 요약해주고, 글 전체 구조(주장-근거-반론 등)를 보여줘.
해석이 어려운 문장 3개를 골라 끊어읽기로 분석해줘.
[지문 붙여넣기]
```

## 리스닝 프롬프트

듣기 음원은 반드시 모의고사 사이트나 실제 영어 강의(유튜브 대학 강의, TED 등)로 듣는다. AI는 스크립트와 받아쓰기 결과를 분석하는 데만 쓴다.

### 받아쓰기 교정

```
아래는 내가 받아쓴 문장들과 원문 스크립트야.
[내 받아쓰기 / 원문 붙여넣기]
틀린 부분을 표로 정리하고, 원인을 분류해줘 (연음, 약모음 탈락, 모르는 단어, 문법 추측 실패).
가장 자주 나온 원인에 맞는 듣기 훈련법을 알려줘.
```

### Listen and Choose a Response 오답 분석

```
짧은 대화 응답 고르기 문제를 틀렸어.
[상대 발화 / 선지 / 내 답 / 정답]
정답이 자연스러운 이유를 화자 의도와 뉘앙스 기준으로 설명하고, 이 상황에서 쓰이는 비슷한 구어 표현 5개를 예문과 함께 알려줘.
```

### 강의 스크립트 분석

```
아래는 학술 강의 스크립트야.
[스크립트 붙여넣기]
1) 강의 구조 (주제 → 세부 포인트 → 예시)를 노트테이킹 형식으로 정리해줘.
2) 교수가 중요하다고 신호를 준 표현(signal words)을 찾아줘.
3) 이 강의로 낼 법한 4지선다 3문제를 만들어줘. 나는 스크립트 안 보고 노트만 보고 풀게.
```

### 노트테이킹 점검

```
강의를 듣고 내가 쓴 노트야. 원문 스크립트도 줄게.
[내 노트 / 스크립트]
노트에서 빠진 핵심 정보와 불필요하게 적은 내용을 짚어주고, 더 나은 노트 예시를 보여줘.
```

## 스피킹 프롬프트

실전 연습은 ChatGPT 음성 모드, 교정은 녹음을 받아쓴 텍스트를 Claude나 ChatGPT에 붙여서 한다. 매일 녹음 1개는 무조건 남긴다.

### Take an Interview 실전 (ChatGPT 음성 모드)

```
토플 2026 Take an Interview 면접관 역할을 해줘.
주제는 [대학 생활 / 기술 / 교육 / 환경 중 하나]로, 질문을 하나씩 해줘.
나는 각 질문에 45초 안팎으로 답할게. 내가 답하면 바로 다음 질문으로 넘어가고, 5개 질문이 끝나면 한꺼번에 피드백해줘.
피드백은 유창성, 발음·억양, 문법 정확도, 내용 구성 4가지를 1~6 밴드로 평가하고, 가장 큰 약점 1개와 고칠 방법을 알려줘.
```

### 답변 교정 (녹음 받아쓴 텍스트)

```
아래는 Take an Interview 질문과 내 답변을 받아쓴 거야.
질문: [질문]
내 답변: [받아쓴 텍스트, 어/음 같은 필러도 그대로]
1) 문법 오류와 어색한 표현을 원문/수정안 표로 보여줘.
2) 필러와 반복이 얼마나 되는지 짚어줘.
3) 내 아이디어는 살리고 5.5 수준으로 다시 쓴 답변 (약 100~120단어)을 보여줘.
```

### Listen and Repeat 쉐도잉 문장 생성

```
캠퍼스 상황(도서관, 수업 안내, 기숙사 등) 문장 20개를 만들어줘.
짧은 것(6~8단어)부터 긴 것(15~18단어)까지 점점 길게, 연음이 많은 문장 위주로.
각 문장마다 연음·강세 포인트를 표시해줘.
```

음성 모드에서 문장을 읽어달라고 한 뒤 바로 따라 말하고, 녹음해서 비교하는 식으로 쓴다.

### 답변 템플릿 다듬기

```
내 Take an Interview 기본 구조는 "입장 → 이유 → 개인 경험 예시 → 마무리"야.
각 단계에서 자연스럽게 쓸 수 있는 연결 표현을 5개씩, 과하게 외운 티 안 나는 것으로 추천해줘.
```

## 라이팅 프롬프트

라이팅은 AI 효율이 가장 좋은 영역이다. "쓰기 → 첨삭 → 안 보고 다시 쓰기" 3단계를 지켜야 실력이 오른다.

### Academic Discussion 문제 생성 + 첨삭

```
토플 2026 Write for an Academic Discussion 문제를 하나 만들어줘.
교수 질문 1개와 학생 2명의 의견(각 50~70단어)을 포함해서.
내가 10분 안에 답안을 쓰면 다음 순서로 피드백해줘:
1) 1~6 밴드 점수와 근거
2) 문법 오류 목록 (원문 → 수정 → 이유)
3) 논리 전개에서 약한 부분
4) 내 아이디어를 살린 5.5 수준 모범답안 (120~150단어)
```

### Write an Email 문제 생성 + 첨삭

```
토플 2026 Write an Email 상황을 하나 줘 (교수, 학과 사무실, 동아리 등에게 요청·문의·사과).
포함해야 할 요구사항 3가지를 명시해줘.
내가 7분 안에 쓰면 요구사항 충족 여부, 어조(격식), 문법을 체크하고 1~6 밴드로 채점해줘.
```

### Build a Sentence 연습

```
토플 2026 Build a Sentence 형식으로 10문제 내줘.
대화 상황 한 줄과, 순서가 섞인 단어 묶음을 주면 내가 올바른 문장으로 배열할게.
간접의문문, 관계사, 수동태, 분사구문 위주로 섞어줘. 다 풀면 채점하고 틀린 문법 포인트를 설명해줘.
```

### 재작성 확인

```
아까 첨삭받은 답안을 모범답안 안 보고 다시 써봤어.
[재작성 답안]
처음 답안 대비 개선된 점과 아직 반복되는 실수를 짚어줘.
```

### 개인 오류 노트 정리 (주 1회)

```
이번 주 첨삭 결과들이야.
[첨삭 내용 붙여넣기]
내가 반복하는 문법·표현 실수를 빈도순 Top 5로 정리하고, 각각 고친 예문 2개씩 만들어줘.
```

## 11월 플랜: 새 유형 익히기 + 기초 체력

11월 목표는 진단으로 약점 영역을 찾고, 네 영역 모든 유형을 한 번 이상 손에 익히는 것이다. 월말 하프 모의에서 영역별 4.5 이상이 기준선이다.

### 하루 3시간 배분

| 시간 | 내용 | 도구 | 쓰는 프롬프트 |
| --- | --- | --- | --- |
| 30분 | 어휘: 전날 오답 단어 퀴즈 + 새 단어 30개 | AI | 오답 기반 어휘 퀴즈 |
| 40분 | 리딩: 학술 지문 1개 + Complete the Words 1세트 | 모의 사이트 + AI | 오답 분석, Complete the Words 생성 |
| 40분 | 리스닝: 강의/대화 2개 + 받아쓰기 10분 | 모의 사이트 + AI | 받아쓰기 교정, 강의 스크립트 분석 |
| 35분 | 스피킹: Listen and Repeat 쉐도잉 20문장 + 인터뷰 3문항 녹음 | ChatGPT 음성 | 쉐도잉 문장 생성, 답변 교정 |
| 35분 | 라이팅: Build a Sentence 10문제 + Email 또는 Discussion 1편 | AI | 라이팅 프롬프트 전체 |

### 주차별 포커스

| 주차 | 포커스 | 이번 주 체크포인트 |
| --- | --- | --- |
| 1주차 (11/2\~11/8) | 진단 + 유형 파악 | ETS Sample Test, Magoosh 무료 모의로 영역별 밴드 기록, 주력 약점 1개 선정 |
| 2주차 (11/9\~11/15) | 리딩·라이팅 문법 기초 | Complete the Words 정답률 80%, Build a Sentence 정답률 80% |
| 3주차 (11/16\~11/22) | 리스닝·스피킹 귀와 입 열기 | 받아쓰기 원인 Top 3 파악, 인터뷰 녹음 15개 누적 |
| 4주차 (11/23\~11/29) | 템플릿 완성 + 하프 모의 | 스피킹·이메일·디스커션 템플릿 확정, 하프 모의로 영역별 밴드 재측정 |

### 약점 영역 조정 규칙

1주차 진단에서 4.0 이하인 영역이 있으면, 그 영역에 하루 20분을 더 주고 가장 높은 영역에서 20분을 뺀다. 2주마다 다시 판단한다.

## 12월 플랜: 시간 재고 실전 훈련

12월 목표는 모든 문제를 실제 시간 제한 안에서 푸는 것이다. 월말 풀 모의에서 영역 평균 4.75 이상이면 1월에 5.0을 노릴 수 있다.

### 하루 3시간 배분 (평일)

| 시간 | 내용 | 도구 | 쓰는 프롬프트 |
| --- | --- | --- | --- |
| 40분 | 리딩 or 리스닝 모의 세트 (요일별로 번갈아), 시간 재고 풀기 | 모의 사이트 | 없음 |
| 30분 | 방금 푼 세트 오답 분석 | AI | 리딩 오답 분석 / Choose a Response 오답 분석 |
| 40분 | 스피킹: 인터뷰 5문항 실전 + 녹음 1개 교정 | ChatGPT 음성 + AI | 인터뷰 실전, 답변 교정 |
| 50분 | 라이팅: Discussion 1편 (10분 제한) → 첨삭 → 재작성, 격일로 Email 추가 | AI | Discussion 생성+첨삭, 재작성 확인 |
| 20분 | 오답 기반 어휘 퀴즈 | AI | 오답 기반 어휘 퀴즈 |

토요일은 하프 모의(약 45분) + 오답 분석 2시간, 일요일은 주간 누적 복습 프롬프트로 다음 주 계획을 조정한다.

### 주차별 포커스

| 주차 | 포커스 | 이번 주 체크포인트 |
| --- | --- | --- |
| 1주차 (11/30\~12/6) | 시간 관리 | 모든 세트를 제한 시간 안에 끝내기, 라이팅 10분 안에 120단어 |
| 2주차 (12/7\~12/13) | 리딩·리스닝 1모듈 정확도 | 세트 정답률 85%, 오답 유형 노트 완성 |

## 점검 루틴과 주의할 점

AI 채점은 방향을 잡는 용도이고, 실제 밴드 판단은 공식·준공식 모의 점수로 한다.

### 매주 일요일 체크리스트

- [ ] 이번 주 영역별 모의 점수 또는 AI 채점 밴드 기록
- [ ] 주간 누적 복습 프롬프트로 반복 실수 Top 3 확인
- [ ] 스피킹 녹음 6개 이상, 라이팅 재작성 4편 이상 했는지 확인
- [ ] 다음 주 약점 영역 시간 조정

### 주의할 점

- AI 채점은 후하거나 들쭉날쭉할 수 있다. 같은 답안을 ChatGPT와 Claude에 각각 채점시켜 차이가 1밴드 이상이면 낮은 쪽을 기준으로 삼는다.
- AI가 만든 리딩·리스닝 문제는 실제보다 쉬울 수 있다. 실력 측정은 모의고사 사이트 문제로만 한다.
- 듣기 음원 없이 스크립트만 보는 건 리스닝 공부가 아니다. 반드시 먼저 듣고, 스크립트는 나중에 본다.
- 첨삭 모범답안을 외우기만 하면 실제 시험에서 무너진다. 재작성은 모범답안을 닫고 한다.
- 시험일은 11월 안에 미리 예약한다. 1월 말은 지원 시즌이라 자리가 빨리 찬다.
