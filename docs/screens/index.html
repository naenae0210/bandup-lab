BandUp Lab 화면

MVP 화면 7개의 정적 디자인이다. 레이아웃, 요소, 문구, 색을 참고하고 실제 구현은 React 컴포넌트로 만든다. 화면 속 점수와 기록은 예시 데이터다.

  • 홈 오늘의 3시간, 영역별 밴드, 주차별 포커스
  • 리딩·리스닝 가져온 문제함, 정답 체크, AI 분석
  • 라이팅 타이머 에디터, AI 첨삭, 재작성
  • 스피킹 녹음, 받아쓰기, AI 피드백
  • 기록 밴드 추이, 오답노트, 단어장, 녹음
  • 설정 AI 연결, 사용량, whisper, 백업
  • 크롬 확장 모의 사이트 위 가져오기 팝업
